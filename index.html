专属管家塑造 Identity & Memory

技术与人设

深度配置 SOUL.md、IDENTITY.md、AGENTS.md 及 USER.md 核心架构。我们不仅内置了 Franziska、Sebas、Toru 以及将维多利亚女仆特质深度「蒸馏」的 Emma 等多元预设角色，更提供全自由度的「自定义管家」选项，亲手捏出你专属的数字陪伴者。

记忆与进化

依托长效记忆机制与自定义 Satellite Skill，管家能在日常相处中精准刻画用户的口味忌口、通勤习惯与消费预算等长尾偏好。

相处成默契

摆脱冷冰冰的单次指令，管家会在陪伴中持续迭代对用户画像的理解，实现「越用越懂你」的深度情感共鸣，让沟通毫无隔阂。

本地生活 Skill 开发 Local Life Skill Matrix

规范生态与矩阵架构

严格遵循 OpenClaw 插件规范，精细化编写 SKILL.md 与原子化底层代码，构建高内聚、低耦合的可插拔本地生活 Skill 矩阵。

四大核心技能链

  • · Satellite 行为特质提取：管家的「触角」，负责深度观察并动态提取用户的行为特质与隐式意图，实现专属 Skill 的自动化沉淀与智能自适应抽取。
  • · schedule-reminder 后台提醒：管家的「大脑」，基于 Cron 机制实现全天候后台常驻守护，无缝联动高德地图 API，提供秒级响应的公交与地铁最优路径规划。
  • · phone-call-skill 电话预约：管家的「双手」，打破数字世界壁垒，赋予其现实世界的跨媒介执行力，支持定时拨号与餐厅电话自动化语音预约。
  • · 全链路生活自动化协同 All-in-One Service：将「搜索、排队、导航、打车」深度集为一体，彻底打破传统 App 间的「信息孤岛」，让管家在一次对话中串联完整出行决策链。

本地智能生活底座

以高德 LBS 为统一感知中枢，贯通 POI 检索、实时排队、路径导航与天气出行等多维数据；配合动态 Mock 沙盒还原真实场景波动，为餐饮、出行、娱乐等高频本地生活场景提供「可感知、可预判、可调度」的底层支撑，让主动陪伴真正落地。

7×24 小时自主协同

突破传统 App 的一问一答模式，实现后台长效任务执行。依托 Satellite 元技能，从近 72 小时记忆日志中嗅探行为模式（log_sniffer），经网关层研判（gateway_router）萃取用户特质并自动编译生成新 Skill（executor_bridge），配合 Cron 定时任务实现全天候自主协同。

② 剩 5 桌时主动提醒
③ 自动呼叫网约车

动态模拟沙盒 Mock Backend

自建 FastAPI 动态 Mock 后端底座。支持随机事件生成与非静态 JSON 返回，真实模拟例如「10 分钟内餐厅从有位突变为满座」的复杂现实交互场景，验证 Agent 的应急调度能力。

全场景多端原生集成 Web & Mini-Program

同时集成 XHAUS 网页控制台（Node.js 后端 + WebSocket 流式对话）与微信小程序前端，通过统一 API 网关代理 OpenClaw Gateway，支持管家性格实时切换与对话历史同步。提供多端无缝切换体验，打破平台壁垒，让全天候管家的主动服务触手可及。
